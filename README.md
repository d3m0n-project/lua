# Lua 
[![Build](https://github.com/d3m0n-project/lua/actions/workflows/build.yml/badge.svg)](https://github.com/d3m0n-project/lua/actions/workflows/build.yml)

This repository is a fork of `https://github.com/lua/lua`, for d3m0n os.

## Compilation

```bash
make
```

You need to have `d3c` installed on your machine. Check [here](../../../compiler/README.md) for more information.


## Installation

```bash
make export
```

The compiled lua executable will be automatically placed in `/programs/bin/`
